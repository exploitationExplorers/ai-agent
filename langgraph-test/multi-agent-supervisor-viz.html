Multi-Agent Supervisor 架构说明

对应源码：langgraph-test/src/multi-agent-supervisor.mjs · 在浏览器中打开本文件即可，无需启动 Node

一句话概括 核心思想

一个调度员（Supervisor）用 LLM 判断该把用户问题交给哪个子代理； 每个子代理只带自己的工具和系统提示，专注一类任务。 用户问「天气 + 小知识」时，调度员会先后派给 weather_agent 和 trivia_agent，而不是让一个模型包办一切。

两个子代理对比

weather_agent

  • 工具：lookup_weather
  • 触发词：天气、气温、下雨、空气
  • Mock 返回：summary、温度区间、AQI

trivia_agent

  • 工具：lookup_city_trivia
  • 触发词：小知识、名胜、历史、介绍
  • Mock 返回：一句城市趣味知识 JSON

Supervisor 调度 prompt（节选）

「你是调度员，只负责选人，不要自己报气温、也不要自己讲城市百科。」— 避免 Supervisor 与子代理职责重叠。

流式输出在做什么 streamMode

const stream = await app.stream(input, { streamMode: ["updates", "values"] });

for await (const event of stream) {
  const [mode, payload] = event;
  if (mode === "updates")  nodePath.push(...Object.keys(payload));  // 哪个节点刚跑完
  else if (mode === "values") finalState = payload;                 // 当前完整状态快照
}

updates：告诉你「刚执行了哪个节点」→ 用来拼 路径: A → B → C
values：整个图的 state（含全部 messages）→ 取最后一条作为最终回答
